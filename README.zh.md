# ⚡ FlowTap（溯流叩击）

键鼠自动化挂机脚本，从 CustomTkinter 到 PySide6 的演进之路。

## 功能

- **键盘模拟**：按键序列录制与回放，支持循环、延迟、组合键
- **鼠标模拟**：点击/移动录制与回放，支持坐标绑定
- **混合模式**：键鼠动作自由组合，同一任务内混合执行
- **任务管理**：多任务列表，一键全部开始/停止
- **预设系统**：保存/加载常用键位配置
- **迷你模式**：无边框悬浮窗，快速操作
- **设置**：不透明度调节、主题切换

## 使用

```
python main.py
```

## 环境

- Python 3.11+
- PySide6 (v3) / CustomTkinter (v1/v2)
- Windows 10/11

## 使用教程

### 1. 新建任务

**用途：** 一张卡 = 一类挂机需求，动作全在卡里编排，多张卡可同时各跑各的。

底部栏点 **「＋ 新建任务」**，生成一张任务卡片。

### 2. 添加动作

**用途：** 动作是任务的最小单元，三个下拉分别添加键鼠动作、流程控制和变量判断。

| 大类 | 包含动作 | 说明 |
|------|---------|------|
| **「+ 键鼠」** | ⌨ 键盘、🖱 点击 | 绑定键盘按键与鼠标点击 |
| **「+ 插入」** | 📷 等图像、🔀 分支、↳ 跳转 | 插入画面相关动作：📷 等图像（等指定画面出现才继续）、🔀 分支（按当前画面匹配的模板选走哪条流程）、↳ 跳转（跳到指定动作接着执行） |
| **「+ 变量」** | 🔢 读数、➕ 变量运算、⚖ 条件分支 | 插入数值相关动作：🔢 读数（OCR 读指定区域的数字写进变量）、➕ 变量运算（对变量做加减计算）、⚖ 条件分支（变量满足条件时走不同流程） |

**怎么加：** ⌨ 按下并保持、全部松开即完成绑定（支持 W+D 组合键）；🖱 在全屏遮罩下点位置绑定，ESC 取消、15 秒超时；等图像 / 分支插入后点行尾「编辑」框选画面（第 4 节），读数用行内「框选」+「试读」（第 5 节），跳转在行内选「跳到」哪一步。

### 3. 编排动作

**用途：** 决定动作的执行顺序与节奏，以及任务之间谁等谁。

- 拖动行左侧 **☰** 手柄调整顺序（列表顺序 = 执行顺序 = 分支优先级）
- 行尾 **✕** 删除该动作
- 行内参数：**持续**（按键保持多久）、**后延**（该动作结束后隔多久执行下一个），按动作类型显示
- 卡片参数：**循环**（一轮跑完隔多久开下一轮；关系切到「在任务N后」时这个框会变成 **延迟**，表示等前一个任务的时长）、**次数**（0 = 无限，跑满自动停）
- **关系:** 选「在任务N后」可让本任务等前一个跑完再开始，选「独立」则互不影响

### 4. 等图像 / 分支（画面识别）

**用途：** 解决「画面还没加载好就乱按」——等目标画面出现再继续，或按当前画面走不同流程，一个任务适配多种场景。

点动作行的 **「编辑」** 进设置页：

- **「框选」** 标定画面区域，**「原图」** 查看标定截图，**「预览」** 实时看匹配得分
- **阈值** 越高越严格；**精确 / 多尺度** 切换（多尺度适配 125%/150% 系统缩放）
- **超时** 填 0 (∞) = 保持等待，一直等到画面出现；**超时后** 可选 跳过 / 跳卡 / 中止
- 分支：多个模板选项，列表顺序 = 优先级，可拖动排序、**「重拍」** 重新标定

### 5. 读数（OCR）

**用途：** 让任务认识屏幕上的数字——读进变量后，交给运算与条件分支做判断。

- **「框选」** 圈出数字区域 → **「试读」** 立即显示 OCR 原文与抽取到的数字
- 取数方式可用「取数方式」下拉换正则；绑定窗口时存客户区相对坐标，窗口拖走也读得准

### 6. 运行控制

**用途：** 任务的启动、暂停与停止；热键让你不用切回 FlowTap 也能控制。

- 底部栏 **▶ 全部开始 / ⏸ 全部暂停 / ■ 全部停止**（暂停保留进度与倒计时，停止清零）
- 单卡 **▶ 开始 / ■ 停止**，启动带倒计时（默认 3 秒，设置里可改，填 0 关闭）
- 全局热键 **F7 开始、F8 停止**——任意界面包括游戏中都能一键控制（可在设置里改键）
- 卡片标题行 **◀/▶** 收起或展开卡片，一次看更多任务

### 7. 窗口绑定

**用途：** 把任务锁在目标窗口上——只有它在前台才动手，切走不乱按，避免误操作别的程序。

设置 → 功能设置 → **「捕获窗口」**：绑定后仅目标窗口在前台时才执行，切走自动等待、切回继续；点 **「解除」** 取消绑定。

### 8. 预设

**用途：** 把整套任务配置存起来复用，换游戏、换场景一键切换，还能导出带到别的机器。

- 卡片顶部下拉选择预设，**加载 / 保存 / 删除**；加载前会弹确认，防止覆盖当前任务
- 设置 → 功能设置 → **导出预设 / 导入预设**：全部预设备份成 JSON，换机器可合并导入

### 9. 迷你模式与设置

**用途：** 挂机时的常驻形态，以及界面与行为的个性化。

- 标题栏 **「—」** 最小化到无边框悬浮迷你窗，开始/停止与主窗口同步
- 设置页分 **外观设置**（窗口标题、不透明度、窗口置顶、记住窗口高度、色彩主题）与 **功能设置**（全局热键、新建任务默认值、启动倒计时、识图匹配、窗口绑定、预设备份），改完立即生效，主题需点底部 **「✓ 应用主题」** 重建界面
