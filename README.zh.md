# ⚡ FlowTap（溯流叩击）

键鼠自动化挂机脚本，从 CustomTkinter 到 PySide6 的演进之路。

## 功能

- **键盘模拟**：按键序列录制与回放，支持循环、延迟、组合键
- **鼠标模拟**：点击/移动录制与回放，支持坐标绑定
- **混合模式**：键鼠动作自由组合，同一任务内混合执行
- **任务管理**：多任务列表，一键全部开始/停止
- **预设系统**：保存/加载常用键位配置
- **迷你模式**：无边框悬浮窗，快速操作
- **设置**：透明度调节、主题切换

## 使用

```
python main.py
```

## 环境

- Python 3.11+
- PySide6 (v3) / CustomTkinter (v1/v2)
- Windows 10/11

### v3.5 — 组合键、设置分页与便携版

**新增**
- **任意组合键** — 绑定 W+D 式自由组合：按住任意键（包括 ESC），全部松开即确认。回放时同时按下、按"持续"时长保持、逆序释放。单键行为不变，旧预设完全兼容
- **设置页分页** — 外观设置（窗口标题、透明度、主题）与功能设置（全局开始 F7 / 停止 F8 热键、新建任务默认值、启动倒计时、窗口置顶、记住窗口高度、预设备份），下拉切换
- **全局开始热键** — F7（可自定义），与停止热键对称
- **预设导入/导出** — 一键备份全部预设为 JSON，可在别的机器合并导入
- **便携版 exe** — 单文件 Windows 打包；配置/预设/日志存在 exe 旁；提权与"应用后重启"均适配打包环境

**变更**
- 新装默认主题改为冰川蓝、90% 透明度
- 底部栏与拖动条升级为窗口级常驻控件——两页几何像素级一致，切页只换按钮（新建任务/全部开始 ↔ 应用）
- 设置页拥有与任务页同款底部栏和拖动条
- 窗口高度单一来源（任务页 auto-size + 用户拖动），切页不再改变窗口尺寸
- 任务区高度只在内容超过初始可视区（约3张折叠卡片）后增长，单任务增量减半
- 外观页顺序：窗口标题 → 窗口透明度 → 色彩主题
- 设置页字体缩小、区块间距收紧、应用按钮变薄

**修复**
- 透明度标签显示 8900% 而非 89%（百分比格式化把已是百分数的值又乘了100）

### v3.4 — 全局停止热键与次数限制

**新增**
- **全局停止热键** — 任意界面（包括游戏中）按 F8（可自定义）立即停止所有任务。设置页 → "全局停止热键"，点"修改热键"后按下任意键重新绑定（ESC 取消），配置保存在 `settings.json`
- **执行次数限制** — 每个任务卡新增"次数"输入框（0 = 无限）。达到上限自动停止：按钮复位"▶ 开始"、状态显示"✓ 已达上限 N 次"、弹出悬浮通知

### v3.2 — 持续按住

**新增**
- **持续按住** — 每个已绑定的键位或鼠标点击可设置"持续"时间：按下后保持指定时长再释放，模拟真人按住，**不是**在持续时间内频繁连点
- UI：每个动作行在描述和"后延"之间新增"持续"时间调整器（0~30秒，0.1秒步进）

**修复**
- **按键捕获焦点** — 开始捕获前清除按钮焦点，空格/回车不再触发"添加键位"按钮点击（此前空格无法绑定且会多出待捕获行）

**变更**
- 主窗口宽度从 346px 调整为 360px（+5%）
- `hold=0`（默认）保持原有的点击/按键行为，与旧预设完全兼容

### v3.1 — Bug 修复与代码清理

**修复**

- **迷你模式按钮** — 任务混合状态下（部分运行、部分停止）按钮文本和响应正确
